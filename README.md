# WinApp-OS

Sistema de gerenciamento de Ordens de Serviço para assistências técnicas (Windows).

## Download

Baixe o instalador mais recente na página de [Releases](https://github.com/WinImports/winappos/releases).

## Instalação

1. Baixe o arquivo `WinApp-OS.Setup.x.y.z.exe` e execute-o.
2. Se o Windows mostrar o aviso "O Windows protegeu o computador", clique em **Mais informações** e depois em **Executar assim mesmo**.
3. Na primeira abertura, o computador precisa estar conectado à internet para validar a licença.

Requisitos: Windows 10 ou 11 (64 bits).
